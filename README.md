Rustlings Practice

My working repository for learning and practicing the Rust programming language through the Rustlings exercises.

About

Rustlings is an official Rust project containing small exercises designed to help developers become familiar with reading and writing Rust code.

I’m using this repository to work through the exercises, experiment with Rust concepts, and document my progress as I build proficiency with the language.

Topics

The Rustlings exercises cover concepts including:

* Variables and data types
* Functions
* Control flow
* Collections
* Ownership and borrowing
* References and lifetimes
* Structs and enums
* Traits and generics
* Error handling
* Iterators
* Smart pointers
* Threads and concurrency
* Macros

Purpose

This repository is part of my continuing computer science and software development studies. Rather than presenting Rustlings itself as an original project, this repository preserves my solutions, experimentation, and progression through the exercises.

I’m working through the exercises incrementally as I develop a stronger understanding of Rust and its ownership-oriented approach to memory safety.
